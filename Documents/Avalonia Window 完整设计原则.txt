## Avalonia Window 完整设计原则

Window 与 UserControl 的层级设计原则基本相同，但 Window 有额外的**窗口级特性**需要考虑。

---

## 🪟 一、Window 基础结构原则

### 1.1 根容器原则
**Window 的根元素必须是 `Panel` 或其派生类（与 UserControl 相同）**

```xml
<!-- ✅ 正确 -->
<Window>
    <Grid>...</Grid>
</Window>

<!-- ✅ 正确 -->
<Window>
    <DockPanel>...</DockPanel>
</Window>

<!-- ❌ 错误：根元素不是 Panel -->
<Window>
    <Button>按钮</Button>
</Window>
```

### 1.2 Window 特有属性

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        x:Class="MyApp.Views.MainWindow"
        x:DataType="vm:MainWindowViewModel"
        x:CompileBindings="True"
        
        <!-- 基础属性 -->
        Title="窗口标题"
        Icon="/Assets/icon.ico"
        
        <!-- 尺寸属性 -->
        Width="800"
        Height="500"
        MinWidth="600"
        MinHeight="400"
        MaxWidth="1200"
        MaxHeight="800"
        
        <!-- 启动位置 -->
        WindowStartupLocation="CenterScreen"
        
        <!-- 装饰与边框 -->
        WindowDecorations="BorderOnly"           <!-- 边框样式 -->
        ExtendClientAreaToDecorationsHint="True" <!-- 扩展客户区到标题栏 -->
        ExtendClientAreaTitleBarHeightHint="32"  <!-- 标题栏高度 -->
        
        <!-- 行为属性 -->
        CanResize="True"
        CanMinimize="True"
        CanMaximize="True"
        
        <!-- 背景 -->
        Background="#F3F3F3"
        
        <!-- 透明窗口 -->
        TransparencyLevelHint="None"              <!-- None/MainWindow/Transparent -->
        SystemDecorations="Full"                  <!-- Full/BorderOnly/None -->>
```

## 🏗️ 二、Window 层级结构原则

### 2.1 标准 Window 层级

```xml
<Window>
    <Grid>
        
        <!-- 1️⃣ 背景层（可选） -->
        <Border Background="{DynamicResource WindowBackgroundBrush}" />
        
        <!-- 2️⃣ 标题栏区域（自定义窗口时） -->
        <Grid RowDefinitions="Auto,*">
            
            <!-- 自定义标题栏 -->
            <Border Grid.Row="0"
                    Height="32"
                    Background="#2D2D2D"
                    PointerPressed="OnTitleBarPointerPressed">
                <Grid>
                    <TextBlock Text="{Binding Title}" 
                               VerticalAlignment="Center"
                               Margin="12,0,0,0" />
                    <StackPanel Orientation="Horizontal"
                                HorizontalAlignment="Right">
                        <Button Content="−" Click="OnMinimize" />
                        <Button Content="□" Click="OnMaxRestore" />
                        <Button Content="✕" Click="OnClose" />
                    </StackPanel>
                </Grid>
            </Border>
            
            <!-- 主内容区域 -->
            <ScrollViewer Grid.Row="1">
                <ContentControl Content="{Binding CurrentPage}" />
            </ScrollViewer>
            
        </Grid>
        
        <!-- 3️⃣ 浮动层（弹窗/通知等） -->
        <Popup IsOpen="{Binding IsPopupOpen}">
            <!-- 弹窗内容 -->
        </Popup>
        
    </Grid>
</Window>
```

### 2.2 标准 Window 完整模板

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
        xmlns:vm="using:MyApp.ViewModels"
        x:Class="MyApp.Views.MainWindow"
        x:DataType="vm:MainWindowViewModel"
        x:CompileBindings="True"
        mc:Ignorable="d"
        
        Title="{Binding Title}"
        Icon="/Assets/icon.ico"
        Width="1024"
        Height="768"
        MinWidth="800"
        MinHeight="600"
        WindowStartupLocation="CenterScreen"
        Background="{DynamicResource WindowBackgroundBrush}"
        WindowDecorations="BorderOnly"
        ExtendClientAreaToDecorationsHint="True"
        ExtendClientAreaTitleBarHeightHint="32">
    
    <!-- 窗口资源 -->
    <Window.Resources>
        <SolidColorBrush x:Key="SidebarBrush" Color="#2D2D2D" />
        <SolidColorBrush x:Key="HeaderBrush" Color="#3C3C3C" />
    </Window.Resources>
    
    <!-- 窗口样式 -->
    <Window.Styles>
        <Style Selector="Button.TitleBarButton">
            <Setter Property="Background" Value="Transparent" />
            <Setter Property="Foreground" Value="White" />
            <Setter Property="BorderThickness" Value="0" />
            <Setter Property="Width" Value="46" />
            <Setter Property="Height" Value="32" />
        </Style>
        <Style Selector="Button.TitleBarButton:pointerover">
            <Setter Property="Background" Value="#555555" />
        </Style>
    </Window.Styles>
    
    <!-- 设计时数据 -->
    <Design.DataContext>
        <vm:MainWindowViewModel />
    </Design.DataContext>
    
    <!-- 根容器 -->
    <Grid>
        
        <!-- 背景层 -->
        <Border Background="{StaticResource SidebarBrush}" />
        
        <!-- 主布局 -->
        <Grid ColumnDefinitions="250,*">
            
            <!-- 侧边栏 -->
            <Border Grid.Column="0" Background="{StaticResource SidebarBrush}">
                <Grid RowDefinitions="Auto,*,Auto">
                    
                    <!-- 侧边栏头部 -->
                    <Border Grid.Row="0" Padding="16,12">
                        <StackPanel Orientation="Horizontal" Spacing="10">
                            <Image Source="/Assets/logo.png" Width="32" Height="32" />
                            <TextBlock Text="{Binding AppName}"
                                       Foreground="White"
                                       FontWeight="Bold"
                                       FontSize="16" />
                        </StackPanel>
                    </Border>
                    
                    <!-- 导航菜单 -->
                    <ScrollViewer Grid.Row="1">
                        <TreeView ItemsSource="{Binding NavItems}"
                                  Background="Transparent"
                                  BorderThickness="0">
                            <!-- 模板 -->
                        </TreeView>
                    </ScrollViewer>
                    
                    <!-- 侧边栏底部 -->
                    <Border Grid.Row="2" Padding="16,12">
                        <Button Content="设置" Command="{Binding SettingsCommand}" />
                    </Border>
                </Grid>
            </Border>
            
            <!-- 主内容区 -->
            <Grid Grid.Column="1" RowDefinitions="Auto,*,Auto">
                
                <!-- 自定义标题栏 -->
                <Border Grid.Row="0"
                        Height="32"
                        Background="{StaticResource HeaderBrush}"
                        PointerPressed="OnTitleBarPointerPressed">
                    <Grid>
                        <TextBlock Text="{Binding CurrentTitle}"
                                   VerticalAlignment="Center"
                                   Margin="16,0,0,0"
                                   Foreground="White" />
                        
                        <StackPanel Orientation="Horizontal"
                                    HorizontalAlignment="Right"
                                    Spacing="0">
                            <Button Classes="TitleBarButton"
                                    Content="−"
                                    Click="OnMinimize" />
                            <Button Classes="TitleBarButton"
                                    Content="□"
                                    Click="OnMaxRestore" />
                            <Button Classes="TitleBarButton"
                                    Content="✕"
                                    Click="OnClose" />
                        </StackPanel>
                    </Grid>
                </Border>
                
                <!-- 主要内容 -->
                <ScrollViewer Grid.Row="1">
                    <ContentControl Content="{Binding CurrentPage}" />
                </ScrollViewer>
                
                <!-- 状态栏（可选） -->
                <Border Grid.Row="2"
                        Height="24"
                        Background="{StaticResource HeaderBrush}">
                    <TextBlock Text="{Binding StatusText}"
                               VerticalAlignment="Center"
                               Margin="12,0,0,0"
                               FontSize="11"
                               Foreground="#CCCCCC" />
                </Border>
                
            </Grid>
        </Grid>
        
        <!-- 全局弹出层 -->
        <Popup IsOpen="{Binding IsNotificationVisible}"
               Placement="Top"
               VerticalOffset="10">
            <Border Background="#333333"
                    CornerRadius="8"
                    Padding="12,8">
                <TextBlock Text="{Binding NotificationMessage}"
                           Foreground="White" />
            </Border>
        </Popup>
        
    </Grid>
</Window>
```

## 🎯 三、Window 特有属性设置原则

### 3.1 窗口装饰配置

```xml
<!-- 标准窗口（默认系统标题栏） -->
<Window SystemDecorations="Full"
        WindowDecorations="Full" />

<!-- 自定义标题栏 -->
<Window SystemDecorations="BorderOnly"
        WindowDecorations="BorderOnly"
        ExtendClientAreaToDecorationsHint="True"
        ExtendClientAreaTitleBarHeightHint="32" />

<!-- 无边框窗口（完全自定义） -->
<Window SystemDecorations="None"
        WindowDecorations="None"
        CanResize="True" />
```

### 3.2 窗口大小行为

```xml
<!-- 推荐：设置合理的尺寸范围 -->
<Window Width="1024"
        Height="768"
        MinWidth="800"
        MinHeight="600"
        MaxWidth="1920"
        MaxHeight="1080"
        CanResize="True" />

<!-- 固定尺寸窗口（不能调整大小） -->
<Window Width="400"
        Height="300"
        CanResize="False"
        CanMinimize="False"
        CanMaximize="False" />

<!-- 起始位置 -->
<Window WindowStartupLocation="CenterScreen" />   <!-- 屏幕中心 -->
<Window WindowStartupLocation="CenterOwner" />    <!-- 所有者中心 -->
<Window WindowStartupLocation="Manual" />         <!-- 手动设置 Left/Top -->
```

### 3.3 透明窗口配置

```xml
<!-- 完全透明窗口 -->
<Window TransparencyLevelHint="Transparent"
        Background="Transparent"
        SystemDecorations="None"
        AllowsTransparency="True">
    <Border Background="#80000000"
            CornerRadius="12">
        <!-- 内容 -->
    </Border>
</Window>

<!-- 亚克力模糊效果（Windows 11） -->
<Window TransparencyLevelHint="Blur"
        Background="Transparent">
    <!-- 内容 -->
</Window>
```

## 📋 四、Window 与 UserControl 对比

| 特性 | Window | UserControl |
|------|--------|-------------|
| **根容器要求** | Panel 派生类 | Panel 派生类 |
| **标题栏** | ✅ 内置/自定义 | ❌ 无 |
| **窗口装饰** | ✅ 可配置 | ❌ 无 |
| **大小调整** | ✅ 可配置 | ❌ 由父级决定 |
| **拖拽移动** | ✅ 可实现 | ❌ 需要父窗口支持 |
| **关闭/最小化** | ✅ 内置事件 | ❌ 无 |
| **窗口资源** | ✅ `Window.Resources` | ✅ `UserControl.Resources` |
| **模态对话框** | ✅ `ShowDialog()` | ❌ 需要父窗口 |
| **数据上下文** | ✅ 通常设置 ViewModel | ✅ 通常设置 ViewModel |

## 🛠️ 五、你的 MainWindow 调整建议

```xml
<Window xmlns="https://github.com/avaloniaui"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
        xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
        xmlns:vm="using:Fountian.AuxiHub.ViewModels"
        x:Class="Fountian.AuxiHub.Views.MainWindow"
        x:DataType="vm:MainWindowViewModel"
        x:CompileBindings="True"                    <!-- 改为 True -->
        mc:Ignorable="d"
        d:DesignWidth="800"
        d:DesignHeight="480"
        Title="Fountian.AuxiHub"
        Background="#F3F3F3"
        ExtendClientAreaToDecorationsHint="True"
        WindowDecorations="BorderOnly"
        WindowStartupLocation="CenterScreen"
        Width="800"
        Height="500"
        MinWidth="600"
        MinHeight="500"
```

## ✅ Window 设计原则自检清单

| 检查项 | 状态 |
|--------|------|
| Window 根元素是 Panel | ☐ |
| 设置了合理的尺寸范围（Min/Max Width/Height） | ☐ |
| 设置了合适的 WindowStartupLocation | ☐ |
| 自定义标题栏时设置了正确的事件处理 | ☐ |
| 使用 ExtendClientAreaToDecorationsHint 时设置了标题栏高度 | ☐ |
| 开启了 x:CompileBindings="True" | ☐ |
| 添加了 Design.DataContext 用于设计时预览 | ☐ |
| 窗口控制按钮（最小化/最大化/关闭）有对应的事件 | ☐ |
| 没有过深的布局嵌套 | ☐ |
| 没有重复的宽度限制 | ☐ |

遵循这些原则，可以设计出**规范、可维护、用户体验良好**的 Avalonia Window。
