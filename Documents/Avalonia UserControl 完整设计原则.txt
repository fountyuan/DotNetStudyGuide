## Avalonia UserControl 完整设计原则

---

## 📐 一、基础结构原则

### 1.1 根容器原则
**UserControl 的根元素必须是 `Panel` 或其派生类**

```xml
<!-- ✅ 正确 -->
<UserControl>
    <Grid>...</Grid>
</UserControl>

<!-- ✅ 正确 -->
<UserControl>
    <StackPanel>...</StackPanel>
</UserControl>

<!-- ✅ 正确 -->
<UserControl>
    <DockPanel>...</DockPanel>
</UserControl>

<!-- ❌ 错误：根元素不是 Panel -->
<UserControl>
    <Button>按钮</Button>
</UserControl>

<!-- ❌ 错误：根元素不能是 ScrollViewer -->
<UserControl>
    <ScrollViewer>...</ScrollViewer>
</UserControl>
```

### 1.2 单一根元素原则
**UserControl 只能有一个直接子元素**

```xml
<!-- ✅ 正确 -->
<UserControl>
    <Grid>
        <TextBlock />
        <Button />
    </Grid>
</UserControl>

<!-- ❌ 错误：多个根元素 -->
<UserControl>
    <TextBlock />
    <Button />
</UserControl>
```

## 🏗️ 二、布局层级原则

### 2.1 标准层级深度（推荐 3-5 层）

```xml
<!-- 推荐的层级结构 -->
<UserControl>                    <!-- 第1层 -->
    <Grid>                       <!-- 第2层：根容器 -->
        <ScrollViewer>           <!-- 第3层：滚动控制 -->
            <StackPanel>         <!-- 第4层：布局容器 -->
                <Border>         <!-- 第5层：视觉容器 -->
                    <StackPanel> <!-- 第6层：内容容器 -->
                        <TextBlock />
                    </StackPanel>
                </Border>
            </StackPanel>
        </ScrollViewer>
    </Grid>
</UserControl>
```

### 2.2 避免过深嵌套

```xml
<!-- ❌ 过深嵌套（7层以上，难维护） -->
<UserControl>
    <Grid>
        <Border>
            <DockPanel>
                <StackPanel>
                    <Border>
                        <Grid>
                            <StackPanel>
                                <TextBlock Text="太深了" />
                            </StackPanel>
                        </Grid>
                    </Border>
                </StackPanel>
            </DockPanel>
        </Border>
    </Grid>
</UserControl>

<!-- ✅ 扁平化重构 -->
<UserControl>
    <Border>
        <DockPanel>
            <TextBlock Text="扁平化" />
        </DockPanel>
    </Border>
</UserControl>
```

## 🎯 三、属性设置原则

### 3.1 属性位置优先级

```xml
<!-- ✅ 推荐：先布局属性，再样式属性，最后数据属性 -->
<Button Grid.Row="0"                    <!-- 布局属性 -->
        Grid.Column="1"
        Margin="10,5"
        Width="100"
        Height="30"
        HorizontalAlignment="Center"     <!-- 对齐属性 -->
        VerticalAlignment="Center"
        Background="Blue"                <!-- 样式属性 -->
        Foreground="White"
        FontSize="14"
        Content="按钮"                   <!-- 数据属性 -->
        Command="{Binding ClickCommand}" />
```

### 3.2 Margin 与 Padding 使用原则

```xml
<!-- ✅ 正确：Margin 在外层容器，Padding 在内层容器 -->
<Border Padding="16">                   <!-- 内边距：内容与边框的距离 -->
    <StackPanel Margin="10">            <!-- 外边距：与父容器的距离 -->
        <TextBlock Text="内容" />
    </StackPanel>
</Border>

<!-- ❌ 错误：重复设置导致布局混乱 -->
<Border Margin="10" Padding="20">
    <StackPanel Margin="15">            <!-- 总边距 = 10+15+20 过于复杂 -->
        <TextBlock Text="内容" />
    </StackPanel>
</Border>
```

### 3.3 宽度控制原则

```xml
<!-- ✅ 正确：只在外层限制最大宽度 -->
<StackPanel MaxWidth="640" HorizontalAlignment="Center">
    <Border>
        <StackPanel>                    <!-- 自动继承父级宽度 -->
            <TextBlock Text="内容" />
        </StackPanel>
    </Border>
</StackPanel>

<!-- ❌ 错误：重复限制 -->
<StackPanel MaxWidth="640">
    <Border>
        <StackPanel MaxWidth="860">     <!-- 无效，永远不会达到 -->
            <TextBlock Text="内容" />
        </StackPanel>
    </Border>
</StackPanel>

<!-- ✅ 正确：内层限制，外层自适应 -->
<StackPanel HorizontalAlignment="Center">
    <Border>
        <StackPanel MaxWidth="860">     <!-- 生效 -->
            <TextBlock Text="内容" />
        </StackPanel>
    </Border>
</StackPanel>
```

## 📝 四、绑定原则

### 4.1 编译时绑定（推荐）

```xml
<!-- ✅ 推荐：开启编译时绑定 -->
<UserControl x:DataType="vm:MyViewModel"
             x:CompileBindings="True">
    <Grid>
        <TextBlock Text="{Binding Title}" />     <!-- 编译时检查，性能更好 -->
    </Grid>
</UserControl>

<!-- ⚠️ 可选：关闭编译时绑定 -->
<UserControl x:DataType="vm:MyViewModel"
             x:CompileBindings="False">
    <Grid>
        <TextBlock Text="{Binding Title}" />     <!-- 运行时绑定，无类型检查 -->
    </Grid>
</UserControl>
```

### 4.2 绑定路径规范

```xml
<!-- ✅ 正确：简洁路径 -->
<TextBlock Text="{Binding UserName}" />

<!-- ✅ 正确：嵌套属性 -->
<TextBlock Text="{Binding User.Address.City}" />

<!-- ✅ 正确：带转换器 -->
<TextBlock Text="{Binding CreateTime, Converter={StaticResource DateConverter}}" />

<!-- ❌ 避免：过长路径 -->
<TextBlock Text="{Binding DataContext.User.Profile.Settings.Name, RelativeSource={RelativeSource AncestorType=Window}}" />
```

## 🎨 五、可读性原则

### 5.1 命名空间顺序

```xml
<!-- ✅ 推荐顺序：Avalonia → MS → Blend → 其他 → 本地 -->
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
             xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
             xmlns:controls="using:MyApp.Controls"
             xmlns:converters="using:MyApp.Converters"
             xmlns:vm="using:MyApp.ViewModels">
```

### 5.2 属性换行规范

```xml
<!-- ✅ 推荐：属性过多时换行 -->
<Button Grid.Row="0"
        Grid.Column="1"
        Margin="10,5"
        Width="120"
        Height="35"
        HorizontalAlignment="Center"
        VerticalAlignment="Center"
        Background="#0078D4"
        Foreground="White"
        FontSize="14"
        FontWeight="SemiBold"
        Content="提交"
        Command="{Binding SubmitCommand}" />

<!-- ✅ 正确：属性少时单行 -->
<Button Content="确定" Command="{Binding OkCommand}" />
```

### 5.3 注释规范

```xml
<!-- ✅ 推荐：区域注释 -->
<!-- 头部区域 -->
<StackPanel>
    <!-- 用户信息 -->
    <Border>
        <!-- 头像 -->
        <Image Source="{Binding Avatar}" />
        <!-- 用户名 -->
        <TextBlock Text="{Binding UserName}" />
    </Border>
</StackPanel>

<!-- ✅ 推荐：复杂逻辑注释 -->
<!-- 当 IsEnabled=True 时才显示此按钮 -->
<Button IsVisible="{Binding IsEnabled}"
        Content="高级设置"
        Command="{Binding AdvancedCommand}" />
```

## 🔧 六、性能原则

### 6.1 控件选择

```xml
<!-- ✅ 性能好：简单布局用 Border -->
<Border CornerRadius="8">
    <TextBlock Text="内容" />
</Border>

<!-- ⚠️ 性能差：简单场景用 Grid 过度 -->
<Grid>
    <Grid.RowDefinitions>
        <RowDefinition Height="Auto" />
    </Grid.RowDefinitions>
    <TextBlock Grid.Row="0" Text="内容" />
</Grid>

<!-- ✅ 需要复杂布局才用 Grid -->
<Grid ColumnDefinitions="Auto,*" RowDefinitions="Auto,Auto">
    <!-- 多行多列表单 -->
</Grid>
```

### 6.2 避免不必要的嵌套

```xml
<!-- ❌ 过度嵌套 -->
<Border>
    <Grid>
        <StackPanel>
            <Border>
                <TextBlock Text="内容" />
            </Border>
        </StackPanel>
    </Grid>
</Border>

<!-- ✅ 简化 -->
<Border>
    <TextBlock Text="内容" Margin="10" />
</Border>
```

## 📱 七、响应式设计原则

### 7.1 使用相对尺寸

```xml
<!-- ✅ 推荐：使用相对尺寸 -->
<Grid ColumnDefinitions="*, 2*, Auto">
    <TextBox Grid.Column="0" />
    <Button Grid.Column="1" Content="搜索" />
</Grid>

<!-- ⚠️ 谨慎：固定宽度 -->
<TextBlock Width="300" />  <!-- 小屏幕可能溢出 -->
```

### 7.2 适配不同分辨率

```xml
<!-- ✅ 使用 MaxWidth 限制最大宽度 -->
<ScrollViewer>
    <StackPanel MaxWidth="800" HorizontalAlignment="Center">
        <!-- 内容在宽屏居中，小屏自适应 -->
    </StackPanel>
</ScrollViewer>

<!-- ✅ 使用 MinWidth 保证最小宽度 -->
<Button MinWidth="80" Content="确定" />
```

## 🛡️ 八、安全原则

### 8.1 绑定安全

```xml
<!-- ✅ 推荐：使用 FallbackValue -->
<TextBlock Text="{Binding UserName, FallbackValue=未知用户}" />

<!-- ✅ 推荐：使用 TargetNullValue -->
<TextBlock Text="{Binding NickName, TargetNullValue=未设置昵称}" />
```

### 8.2 资源引用安全

```xml
<!-- ✅ 推荐：使用 DynamicResource 支持运行时切换 -->
<Border Background="{DynamicResource BackgroundBrush}">

<!-- ✅ 推荐：使用 StaticResource 静态资源 -->
<Border Background="{StaticResource DefaultBrush}">

<!-- ⚠️ 注意：确保资源存在，否则使用 FallbackValue -->
<Border Background="{StaticResource MyBrush, FallbackValue=White}">
```

## 📋 九、完整模板

```xml
<UserControl xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:d="http://schemas.microsoft.com/expression/blend/2008"
             xmlns:mc="http://schemas.openxmlformats.org/markup-compatibility/2006"
             xmlns:vm="using:MyApp.ViewModels"
             x:Class="MyApp.Views.MyView"
             x:DataType="vm:MyViewModel"
             x:CompileBindings="True"
             mc:Ignorable="d">
    
    <!-- 设计时数据上下文 -->
    <Design.DataContext>
        <vm:MyViewModel />
    </Design.DataContext>
    
    <!-- 根容器 -->
    <Grid>
        
        <!-- 背景（可选） -->
        <Border Background="{DynamicResource ApplicationBackgroundBrush}" />
        
        <!-- 主体滚动区域 -->
        <ScrollViewer HorizontalScrollBarVisibility="Disabled"
                      VerticalScrollBarVisibility="Auto">
            
            <!-- 内容容器 -->
            <StackPanel Margin="16"
                        MaxWidth="800"
                        Spacing="12"
                        HorizontalAlignment="Center">
                
                <!-- 卡片1 -->
                <Border Background="White"
                        CornerRadius="8"
                        Padding="16">
                    <StackPanel Spacing="8">
                        <TextBlock Text="卡片标题"
                                   FontWeight="SemiBold"
                                   FontSize="16" />
                        <!-- 卡片内容 -->
                    </StackPanel>
                </Border>
                
                <!-- 卡片2 -->
                <Border Background="White"
                        CornerRadius="8"
                        Padding="16">
                    <StackPanel Spacing="8">
                        <!-- 卡片内容 -->
                    </StackPanel>
                </Border>
                
            </StackPanel>
        </ScrollViewer>
        
        <!-- 浮动层（可选） -->
        <Popup IsOpen="{Binding IsPopupOpen}"
               PlacementTarget="{Binding #targetControl}">
            <!-- 弹窗内容 -->
        </Popup>
        
    </Grid>
</UserControl>
```

## ✅ 十、自检清单

| 检查项 | 状态 |
|--------|------|
| UserControl 根元素是 Panel | ☐ |
| 没有过深的嵌套层级（≤5层） | ☐ |
| 开启了 x:CompileBindings="True" | ☐ |
| 指定了 x:DataType | ☐ |
| Margin/Padding 使用合理 | ☐ |
| 没有重复的 MaxWidth 限制 | ☐ |
| 使用了 FallbackValue 处理空值 | ☐ |
| 复杂布局使用了 Grid | ☐ |
| 简单布局使用了简单控件 | ☐ |
| 代码缩进统一 | ☐ |
| 添加了必要的注释 | ☐ |

遵循这些原则，可以写出**可维护、高性能、跨平台兼容**的 Avalonia UserControl。
